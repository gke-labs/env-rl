# Harbor environment provider: acceptance criteria

Status: last checked 2026-11-15 against Harbor `v0.26.0` and Harbor `main` at `ec6aeab7`, with
`sandboxenv-rl` `main` at `1cd63f30`. Unit tests are in
[`integrations/harbor/tests`](../../../integrations/harbor/tests) and run hermetically against the
fake ate-env-api in `tests/fakes.py`; `test_trial.py` and `test_tools_layer_docker.py` need a docker
daemon and are skipped without one; `test_e2e.py` runs against a live `ate-env-api` when
`SUBSTRATE_E2E_API_URL` is set.

Status values: **met** (on `main`, with the tests named), **PR** (an open pull request meets it),
**open** (planned, no pull request), **not planned** (decided against; see [README.md](./README.md)
section 3).

Ids run `HB-1` to `HB-29` in document order. The letter in a section title names the group and is
not part of the id.
