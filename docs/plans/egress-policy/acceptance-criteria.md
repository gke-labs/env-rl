# Egress policy: acceptance criteria

Status: describes `main` at `a9b5c19` and Substrate `v1.0.0`. All rows are open. The plan is in
[README.md](./README.md). Each row names the tests a pull request adds to meet it.

## Scope

A caller sets an environment's egress policy on `CreateEnvironment` and replaces or reads it with
`SetEnvironmentEgressPolicy` and `GetEnvironmentEgressPolicy`. `ate-env-api` stores it as the
actor's Substrate `EgressPolicy`. Unit tests run against `internal/internaltest/fakecontrol`. The
e2e rows run in the Kind E2E job (`hack/ci/e2e.py`).

Status values: **open** (planned, no pull request), **PR** (an open pull request meets it), **met**
(on `main`, with the tests named).

## Criteria

| ID    | Criterion                                                                                                                                                                                                                                                                                                                                      | Status | Tests                                                              |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ------------------------------------------------------------------ |
| EG-1  | `CreateEnvironment` with an `egress_policy` stores the actor's Substrate policy with the same rules before it responds. The actor is still suspended when the policy is written.                                                                                                                                                               | open   | `TestEG1CreateEnvironmentWritesEgressPolicyBeforeWake`             |
| EG-2  | `CreateEnvironment` with an `egress_policy` that has no rules stores a Substrate policy with no rules (deny all).                                                                                                                                                                                                                              | open   | `TestEG2CreateEnvironmentEmptyRulesStoresDenyAll`                  |
| EG-3  | `CreateEnvironment` with an invalid rule returns `InvalidArgument` and creates no actor. Invalid rules: an IP or URL hostname, a bad wildcard, no hostnames, a port outside 1..65535, more than 16 ports, ports and `all_ports` together, `tls_passthrough` without ports, more than 256 rules, and two rules that tie on a hostname and port. | open   | `TestEG3CreateEnvironmentInvalidEgressRule`                        |
| EG-4  | When the policy write fails, `CreateEnvironment` deletes the actor and returns the policy write's error code.                                                                                                                                                                                                                                  | open   | `TestEG4CreateEnvironmentPolicyFailureDeletesActor`                |
| EG-5  | When the policy write and the delete both fail, `CreateEnvironment` returns an error that names both failures.                                                                                                                                                                                                                                 | open   | `TestEG5CreateEnvironmentPolicyAndDeleteFailure`                   |
| EG-6  | `CreateEnvironment` without `egress_policy` makes no egress policy call and returns what it returns on `main` today.                                                                                                                                                                                                                           | open   | `TestEG6CreateEnvironmentWithoutEgressPolicy`                      |
| EG-7  | `SetEnvironmentEgressPolicy` on a running environment replaces the stored policy with the new rules, using the current `uid` and `version` as preconditions, and returns it.                                                                                                                                                                   | open   | `TestEG7SetEgressPolicyReplacesPolicy`                             |
| EG-8  | `SetEnvironmentEgressPolicy` on a suspended environment stores the policy without waking it. The next wake runs with that policy.                                                                                                                                                                                                              | open   | `TestEG8SetEgressPolicySuspendedNoWake`                            |
| EG-9  | `SetEnvironmentEgressPolicy` on an environment with no policy creates one.                                                                                                                                                                                                                                                                     | open   | `TestEG9SetEgressPolicyCreatesWhenMissing`                         |
| EG-10 | When every update attempt gets `Aborted` (a concurrent writer), `SetEnvironmentEgressPolicy` stops after a bounded number of attempts and returns `Aborted`.                                                                                                                                                                                   | open   | `TestEG10SetEgressPolicyConflictRetriesThenAborted`                |
| EG-11 | `SetEnvironmentEgressPolicy` with an invalid rule returns `InvalidArgument` and leaves the stored policy unchanged.                                                                                                                                                                                                                            | open   | `TestEG11SetEgressPolicyInvalidRule`                               |
| EG-12 | `SetEnvironmentEgressPolicy` and `GetEnvironmentEgressPolicy` on an unknown environment return `NotFound`.                                                                                                                                                                                                                                     | open   | `TestEG12EgressPolicyUnknownEnvironment`                           |
| EG-13 | `GetEnvironmentEgressPolicy` returns the rules last stored by `CreateEnvironment` or `SetEnvironmentEgressPolicy`, defaults included (80 for `http`, 443 for `https`).                                                                                                                                                                         | open   | `TestEG13GetEgressPolicyReturnsStoredRules`                        |
| EG-14 | `GetServerInfo` lists the feature `egress_policy`.                                                                                                                                                                                                                                                                                             | open   | `TestEG14ServerInfoListsEgressPolicy`                              |
| EG-15 | The Go SDK sends `egress_policy` on create and serves set and get with the same codes as the server. It refuses `egress_policy` when the server does not list the feature.                                                                                                                                                                     | open   | `TestEG15GoClientEgressPolicy`                                     |
| EG-16 | The Python SDK matches the Go SDK for `EG-15`.                                                                                                                                                                                                                                                                                                 | open   | `test_eg16_egress_policy` in `clients/python/tests/test_client.py` |
| EG-17 | Live: in an environment created with a policy that allows one host, a lookup of a host no rule allows gets `NXDOMAIN`, and the allowed host resolves.                                                                                                                                                                                          | open   | `TestEG17E2EEgressPolicyDNS` in `clients/go/e2e_test.go`           |
| EG-18 | Live: after `SetEnvironmentEgressPolicy` allows a second host on a running environment, that host resolves within 15 seconds.                                                                                                                                                                                                                  | open   | `TestEG18E2ESetEgressPolicyLive` in `clients/go/e2e_test.go`       |
