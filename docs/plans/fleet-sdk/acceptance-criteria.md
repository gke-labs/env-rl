# Acceptance criteria: client-only fleet gaps

Status: describes `main` at `661c66e0`. FL-1 to FL-4 are built by #397, FL-5 to FL-9 by #395, and
FL-18 and FL-19 by #396; the other rows are open. The plan is in [README.md](./README.md); issue
#123. The tests of the open rows do not exist yet; each pull request of the plan adds the tests of
its rows and marks them met.

Fleet types: a row that names neither `SandboxFleet` nor `AsyncSandboxFleet` applies to both (FL-10
to FL-15, FL-18, FL-19). FL-5 to FL-7 apply to `SandboxFleet` only: `AsyncSandboxFleet` refuses
`exit_hooks=True`, and #398 tracks exit hooks for it.
